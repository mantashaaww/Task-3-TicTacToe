# Tic-Tac-Toe Web Application

This project is **Task-03** of my Web Development Internship at Prodigy Infotech.

## Features
- Two-player tic-tac-toe game
- Detects wins and draws
- Reset button to start a new game
- Interactive and responsive UI

## How to Use
1. Open `tic-tac-toe.html` in any web browser
2. Click on the cells to place X or O
3. First player to get three in a row wins
4. Click "Reset Game" to start over
